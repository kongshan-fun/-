原创竖屏 H5 文字修仙生存 RPG。**当前 GitHub `main` 最新游戏版本为 V90.8**，默认入口为 [`index.html`](index.html)，与 [V90.8 独立发布文件](releases/山野修仙记_V90.8_五阶洞府与高阶炼制版.html) 保持一致。

> **状态说明（2026-10-18）：** V90.8 已由 [PR #19](https://github.com/kongshan-fun/-/pull/19) 合并进入 `main`，但这只代表仓库版本更新。**没有据此认定已部署公网、已在 TapTap 上架，或已接入真实广告与云排行榜。**

## 立即体验

1. 下载或克隆本仓库。
2. 使用浏览器打开根目录 `index.html`，或打开 `releases/山野修仙记_V90.8_五阶洞府与高阶炼制版.html`。均为独立 H5 单文件，无需先构建或安装依赖。
3. 旧档跨浏览器、域名或 H5 容器迁移前，先在游戏内导出备份 JSON；浏览器存储来源不同可能无法自动共享存档。

## 确定性构建及回归

在仓库根目录使用 Python 3、Node.js 22（或兼容版本）运行：

```bash
python3 tools/build_v908_from_main.py
python3 tools/extract_v908_tests.py
node tests/run_v908_regression.cjs
```

构建工具会先校验冻结版与补丁的 SHA-256，再生成 `index.html` 和 V90.7/V90.8 版本文件；应始终让默认入口与 V90.8 版本文件内容相同。V90.8 合并时的 GitHub Actions 完整回归已通过，见 [PR #19](https://github.com/kongshan-fun/-/pull/19) 与 [验收报告](docs/V908_高阶洞府与装备炼制进阶设计及验收报告.md)。100 档测试属于**加速里程碑回归**，不代表自然游玩的真实通关率。

## 发行与数据边界

这是**可离线试玩的 H5 游戏代码**，不是已核实上线的生产服务。当前排行榜仅在本机，没有账户、云同步或真实广告 SDK。Android、iOS 实机和 TapTap H5 容器仍需单独验收；改动存档格式时要维持旧档兼容。更新玩法请同步修改确定性构建源、默认入口、版本文件与回归测试，避免下次构建还原旧界面或旧版本标识。
