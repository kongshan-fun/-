# 青岚问道 · V9 洞府营建版

原创纯文字修仙生存 RPG。五张 8×8 地图，黑白极简手机界面，左下角居中九宫格、展开地图、采集、营建洞府、仓库、炼器室、丹房、首领、图鉴与新手教程。

## 运行

- **试玩：** 直接在浏览器打开 [青岚问道_V9_洞府营建.html](青岚问道_V9_洞府营建.html)，无需构建或安装依赖。
- **修改代码：** 从 `index.html` 与 `src/` 开始。分离源码便于编辑、调试和提交。
- **重新生成单文件：** `python build.py`（Python 3，标准库）。
- **基础检查：** `node tests/smoke.test.js`（Node.js 18+）。

## 工程结构

| 路径 | 内容 |
| --- | --- |
| `src/data.js` | 五境地图、物品、配方、装备、事件、建筑和引导数据 |
| `src/engine.js` | 战斗、采集、成长、营建、仓库和规则判定 |
| `src/ui.js` | 地图、面板、教程、图鉴、存档等界面交互 |
| `src/style.css` | 黑白手机布局与弹窗样式 |
| `index.html` | 分离源码入口 |
| `青岚问道_V9_洞府营建.html` | 自包含离线试玩文件 |
| `docs/完整文字教程.html` | 17 章图文之外的完整文字说明 |
| `tests/smoke.test.js` | GitHub 初始代码基础校验 |

## 当前内容与约束

五境探险，左下角九宫格移动与按需展开大地图；必须选址筑庐才能定居，七类实际生效的建筑（洞府、仓房、炼器室、丹房、静室、灵田、山门），每境各自独立仓库，高级炼器/炼丹与房间等级绑定。11 阶段实操新手引导与完整文字教程。界面不依赖图片素材，不翻页，不因提示弹窗导致布局跳动。

**注意：** 这是可玩的离线原型，不是生产环境网站；此提交不部署 GitHub Pages，也不连接真实账户或广告。旧版存档可在游戏设置中通过 JSON 导出/导入。

原 V9 离线交付压缩包中包含更全面的浏览器和五境压力测试及实机截图；本次仓库初始提交先纳入核心源码、可玩成品、教程与基础检查。后续可将回归脚本逐项迁入并建立 CI。

## 开发建议

保持 `src/engine.js` 与 DOM 解耦，修改玩法时同时修改 `src/data.js`、`src/ui.js` 及教程；提交前运行构建和基础检查。涉及存档格式需保留旧档迁移路径。
