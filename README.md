# 山野修仙记 V90.75 · 洞天十二阶

竖屏、自包含 H5 文字修仙生存游戏。本分支基于 V90.74 存档安全候选版，完成唯一洞府、十二阶设施、逐图装备、赋灵修复、动态成长指引和可配置补给。

**这是独立 H5 交付分支，不表示 TapTap 正式服已更新。** 当前分支不自动合并 `main`，不提交平台审核，不修改正式玩家数据。独立版沿用本地试玩奖励逻辑；TapTap 实际激励视频、云存档及线上排行榜适配层不在本交付的运行环境中。

## 开始游戏

解压 H5 包，打开根目录 `index.html`。现代桌面浏览器可以直接打开；也可以运行 `python -m http.server 8080` 后访问本机服务。手机应通过正常 HTTP/HTTPS 静态站点进入。游戏源文件不依赖外部 CDN 或联网资源。

换浏览器、域名、文件路径或设备之前，先在游戏设置里导出 JSON。浏览器存储按来源隔离，换路径可能看不到原存档；不要因此清除浏览器数据。

## 本版内容

- 每个难度、种族、档位、当前轮回只有一座洞府。固定按钮直接进入，返回探索保留原地图和坐标。战斗、秘境中不能借洞府脱离危险。
- 洞府、仓房、炼器室、丹房、静室、灵田开放十二阶；同阶对应同序地图。青岚护山阵仍是一次性的地图仪式，不伪装成重复升级设施。
- 仓房物资容量从一阶600增至十二阶250000；独立装备仓位从48增至1600。随身器囊仍为36件，储物袋仍只扩展随身负重。
- 装备和常规储物袋按十二张地图分类；配方检查已解锁地图、当前境界及同阶设施，避免只凭囤料越级。
- 赋灵只消耗当前修为 `xp` 和灵石，不再读取停用的 `daoXp`。熟练度在成功赋灵后增加。余额不足不抽词条、不扣材料。
- 修行目标与地图进度分别按实际状态显示。旧雷考、问心等故事为可选见闻，不再成为错误的破境前置；已完成选择保留。
- 新增十二阶回血、回灵、灵膳、灵饮，共48个配方。四个快捷槽可自行选择同类补给，配置随当前存档保存；没有库存不会擅自换用其他药。
- 战斗使用回血、回灵仍占一回合；食物饮水限战外。快捷栏只用随身物品，不远程取仓物。

## 旧档迁移

详情见 `docs/v975/迁移与回滚.md`。新版本读取旧版多洞府时，合并所有仓物和装备，各设施取等效最高等级，旧五阶对应新1/3/5/9/12阶。第一次保存前保留原始旧档；归档失败则阻止覆盖。超量仓物保留，只限制继续存入。

升级后可在“设置 → 存档与备份 → 导出 V90.75 升级前存档”导出独立原始归档。**回滚必须使用升级前JSON和旧版游戏，不要用旧版打开新结构存档。**

## 构建和验收

```bash
python tools/build_v975_from_main.py
python tools/check_entry_consistency.py --rebuild
node tests/run_v975_acceptance.cjs
python -m pip install playwright==1.56.0
python -m playwright install chromium
python tests/v975_browser.py
python tools/package_v975.py
```

Node 22、Python 3.10以上。浏览器测试默认真实HTTP来源和 `localStorage`，覆盖实际点击、导入失败保护、旧档导出、页面隐藏救援和六种视口。受管理环境禁止导航时，可显式运行 `--offline-dom` 进行DOM及存储替身测试，报告会标明差别，不能冒充真实来源验证。

主动维护的验收入口是 `run_v975_acceptance.cjs`，不是旧版43层入口。旧测试中五阶洞府、每图定居、旧道行、旧剧情前置等假设已不适用于本版。当前20套引擎/迁移测试和浏览器矩阵的覆盖对应表在 `docs/v975/验收范围.md`；原历史文件保留供追溯，不删除失败掩盖问题。

100档通关与600档矩阵使用合成存档、加速修为和测试物资，证明状态流程与隔离，不宣称自然游玩难度、经济、通关率已获得真实运营验证。

## 维护入口

- `src/v975/data.js`：十二阶设施、补给、配方与帮助文案。
- `src/v975/engine.js`：唯一洞府、迁移、修为消费与补给规则。
- `src/v975/ui.js`、`style.css`：固定洞府、十二图分类、动态目标与快捷配置。
- `tools/build_v975_from_main.py`：基于冻结V90.74生成单文件；禁止直接修改生成物后忘记同步构建器。
- `releases/山野修仙记_V90.75_洞天十二阶完整版.html`：与根目录入口字节一致。
- `artifacts/v975/`：实际测试报告、日志、截图，不包含真实玩家存档。
