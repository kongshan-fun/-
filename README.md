# 青岚问道 V10 · 寿元与洞府经营

离线单机 H5 修仙文字探索生存 RPG，独立原创代码；五境（每境 8×8）、黑白窄屏、九宫格移动、点击文字资源采集、洞府仓库、炼器室、丹房、静室、灵田、山门、战斗与新手教程。

## 即刻试玩

打开 `青岚问道_V10_寿元与洞府.html`，无需联网与构建；或打开 `index.html` 加载 `src` 的分离源码。桌面仍居中显示 400px 手机宽度，长内容仅固定面板内滚动。

## V10 寿元规则（重要）

- 初始寿元 **56 年**，每经过 **4 游戏日耗 1 年**；不打开游戏就不会推进时间。
- 战败或饥渴导致倒下，额外折寿 **16 年**，恢复转移另计半个游戏日；不再仅损失一半材料。
- 突破炼气 3/6/9 层、筑基特定层级时额外延寿。三阶丹房可炼 **延寿丹**，一枚延寿 8 年、每名角色最多服用 2 枚。
- **寿元归零将永久结束当前角色**：立即从浏览器存储清除本版主存档、自动备份和同来源的旧版继承存档，保留无角色内容的终结标记以防旧档自动复活。点击「重新轮回」才生成新角色。
- 使用 JSON 外部导出或另一浏览器保存的副本可手动回档：离线单机无法防止外部文件作弊，因此此规则只承诺在当前浏览器存储源内实现，不宣称跨设备不可逆。
- V9 正常升级为 V10 时，会在新键中复制并迁移旧档，不追扣旧版所有游玩时长以避免突然删档；发生 V10 真正寿尽时才清除该来源的相关存档键。

## V10 洞府经营优化

- 灵田每游戏日成熟一批，**最多积累 3 批**，超过三批不会无限囤积；领取保留未满一日的进度。
- 灵田收获先放当地仓房，满仓自动进入背包，背包也满时留在原地待拾，不丢失或跨境瞬移。
- 仓库支持单种物资 **存5 / 存全** 及 **取1 / 取5**，还增加了「出行补给」：从本仓向背包补充指定数量的灵果、清水、回春散和回灵丹，不凭空产物资，保持总量守恒、负重限制。
- 洞府付灵石补给不再瞬间完成，消耗 45 游戏分钟；长休按真实跨过的游戏分钟计时与折寿，堵住跳时绕过寿元的漏洞。

## 开发、构建与校验

- 数据定义：`src/data.js`；规则：`src/engine.js`；界面：`src/ui.js` + `src/style.css`。
- 构建单文件：`python build.py`；同步教程：`python build_docs.py`（需 Node.js + Python 3）。
- Node：`node tests/v10_regression.test.js`；`node tests/v10_lifespan.test.js`；`node tests/v10_campaign.test.js --all`。
- Chromium：`python tests/v10_browser_smoke.py`、`python tests/v10_lifespan_browser.py`（需 Playwright 与 Chromium）。
- 环境限制：本地容器的 Chromium 阻止 localhost 和 file:// 导航，所以浏览器测试使用 `set_content` 与明确的隔离存储适配器；真实 origin 下的浏览器长期存储/删除仍需外部实测。
