# 青岚问道 V12 · 凡界飞升

原创黑白极简手机文字修仙生存 RPG。12 张 **8×8 地图（768 格）**，从炼气、筑基一路到金丹、元婴、化神、炼虚、合体、大乘、渡劫，最终飞升；**仙界保留到后续扩展**，飞升后保存原角色、两条独立分支与收集进度，不删除存档。

## 开始试玩

- 直接打开 [青岚问道_V12_凡界飞升.html](青岚问道_V12_凡界飞升.html)。完全离线，手机优先；PC 浏览器居中窄屏（最大400px）。
- 老玩家务必先在旧文件“设置”中导出 JSON；切换浏览器或 HTML 路径可能不共享 localStorage。
- 两名角色：玄锋剑修（战斗输出）与青木丹修（采药恢复），有独立寿元、地图、仓库、装备和存档。

## 成长说明

- 原 V11 前五图玩法和原有等级1–18的成长方式保留。后七境采用独立道行和破境机制：先建本境洞府、采集、修祭坛、败首领，然后在府中消耗道行与两个特有道材完成大境界突破。
- 最后的“渡劫→飞升”不是自动通关提示，须在飞升天门实际点击飞升、扣除道行和飞升材料。
- 原有的仓房、炼器室、丹房、独立仓储、五级法器品质、寿元流逝与战败折寿、寿尽只清理该角色以及图鉴继续生效。
- 继续保持黑白灰极简、左下 3×3 小地图、“我”居中点击邻格移动、展开大地图、点文字采集、弹窗不挤动、完整角色教学。

## 源码和打包

- `index.html`：分离代码入口；`src/data.js`：12区+材料、境界和首领数据；`src/engine.js`：修行、战斗、飞升核心规则；`src/slots.js`：独立角色存储；`src/ui.js`+`src/style.css`：界面布局和教程。
- `python build_docs.py`：根据真实游戏数据生成完整教程、数值表和 `docs/当前游戏数据.json`；`python build.py`：再生成自包含的 `青岚问道_V12_凡界飞升.html`。无额外前端依赖。
- 测试：`node tests/smoke.test.js && node tests/v10_regression.test.js && node tests/v10_lifespan.test.js && node tests/v11_characters.test.js && node tests/v10_campaign.test.js --all --both-roles && node tests/v12_ascension.test.js`。已安装 Playwright + Chromium 可执行 `python tests/v12_browser.py`。

## 验收与边界

详见 [V12 验收报告](docs/V12_验收报告.md)。验收中的“飞升路线”来自对地图有先验了解的模拟玩家，不能代表真正新手的长期数值平衡。浏览器存储采用隔离适配器，不宣称原生手机设备长期持久性测试。任何 PR 必须通过 CI、开发者审核后才能合并 `main`。目前未上线仙界、云存档和广告。
