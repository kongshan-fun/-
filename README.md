# 青岚问道 V14 · 人妖同途

黑白手机文字修仙生存 RPG。人族与妖族共用十二境剧情与飞升终点，拥有各自境界、随机天赋、100个独立档位。电脑仍显示最大400px的手机游戏。

## 直接游玩

打开 `青岚问道_V14_人妖同途.html`（完整单文件），或使用 `index.html` 开发入口。第一次进入：选择种族 → 选择空档 → 抽取天赋并填道号 → 确认入世。左下九宫格移动，上方点字采集，大地图按需展开。

## 本版已实现

- 选族、选档、命格三个完整不透底的页面；确认按钮与返回入口固定，长说明只在面板内部滑动。
- 人族：灵根、五行偏性、悟性、根骨、气运；妖族：血脉、本相、灵智、妖躯、气运。
- 人族修炼至渡劫飞升；妖族启灵、通脉、妖丹、化形、妖王、妖皇、妖尊、妖圣、渡劫、飞升。妖族路线是本作编排，不宣称作品间存在统一命名。
- 天赋实际影响初始气血、法力、攻击、修为、战斗、恢复、采药或装备品质。化形不改种族。
- 入世前免费重抽，入世后锁定；不通过刷新或切档重新抽取。
- 两族各100档、共200个逻辑档位；寿尽只终结当前档。存储配额不足时停止写入并提示，不宣称200个后期档必能装进所有浏览器。
- 旧剑修、丹修都可选择空位显式继承为人族“旧世传承”。旧属性与技能保留，不叠加新抽天赋；原档不删除，不强行合并两个001档。
- 十二地图、洞府、独立仓房、炼器丹房、灵田、图鉴、11段实操引导、寿元及凡界飞升保留。仙界仍未开放。

## 开发

`src/birth.js` 定义种族/命格与结算；`help.js` 是权威教程；`data.js` 是世界配置；`engine.js` 是无DOM规则；`slots.js` 是种族与档位存储；`entry.js`/`entry.css` 是完整入口页面；`ui.js`/`style.css` 是主游戏UI。

```sh
python build_docs.py
python build.py
node tests/v14_core.test.js
node tests/v14_lifespan.test.js
node tests/v14_races.test.js
node tests/v14_campaign.test.js --all --both-roles
node tests/v14_ascension.test.js
python tests/v14_browser.py
python tests/v14_onboarding.py
```

Python脚本只用标准库；浏览器测试另外需要Playwright与Chromium。默认浏览器测试注入隔离的内存存储。支持HTTP访问的环境可设 `QINGLAN_REAL_ORIGIN=1` 使用真实本地HTTP来源和localStorage；这仍不等于Android/iOS硬件及长期存储验证。

完整教程见 `docs/完整文字教程.html`；概率及效果见 `docs/V14_种族与命格数值.md`。本轮没有联网账号、付费抽卡、云存档或网站部署。

## 存档安全

更换HTML路径、浏览器或设备前先导出JSON。本版不读取现实时间来扣寿命。旧档迁入不覆盖新档，妖族不能继承人族档。离线JSON属于玩家可管理文件，不提供服务器级防改档保证。

`main` 不是这次自动发布目标；开发分支通过检查与所有者审核后再讨论合并。
