# 婴灵古墟 → 化神云海 进不去：原因分析与修复

日期：2026-10-24
玩家反馈：在「婴灵古墟」无法进入下一张地图（化神云海）

## 一、开图规则（现状）

```
开图条件（zone 索引 i）：cleared[i] 且（i≥5 时）major ≥ i-3
  i=6 婴灵古墟 → 要开放 i=7 化神云海，必须 cleared[6] 且 major ≥ 3（化神）
major 对应：金丹=1 元婴=2 化神=3 炼虚=4 合体=5 大乘=6 渡劫=7
```

也就是说：**打败婴灵古墟首领还不够，还要把境界从元婴突破到化神**。

## 二、两个真实原因

### 原因 A（代码缺陷，本次已修）：第 6 图起击败首领不刷新开图

`winBattle()` 的 boss 分支原来只有：

```js
if(i<=4) this.s.unlocked = Math.max(this.s.unlocked, Math.min(D.ZONES.length, i+2));
```

**只在前五图（i≤4）更新**。丹霞雷渊（i=5）、婴灵古墟（i=6）及以后击败首领后，
`unlocked` 不变——而 `recalcUnlocked()` 只在 `breakthrough()` 里调用。

于是玩家如果**境界已经够**（major≥3），打完婴灵古墟首领，出行列表里的化神云海仍然锁着，
**必须退出重进**（重载存档触发 normalize 重算）才会开放。
这正是「进不去下一张地图」最典型的症状。

### 原因 B（设计门槛，不是 bug）：还没突破到化神

如果玩家仍是元婴（major=2），就算首领打完也不会开图——需要：
1. 在「婴灵古墟」**自己的洞府**（不是旧图洞府）
2. 洞府 → 修炼 → 破境条件 → 完成「**元婴问心**」三重试炼
3. 修为与道材齐备后点「破境」→ 化神

很多玩家卡在这里，因为目标提示只说「先在洞府破境」，没写要哪个境界、要先做问心。

## 三、修复（V90.68）

| # | 改动 | 说明 |
|---|---|---|
| 1 | boss 胜利后统一 `this.recalcUnlocked();` | 所有地图（含 i≥5）击败首领立即重算开图，不必重进 |
| 2 | 解锁提示按实际状态改写 | 够境界时提示「已解锁 化神云海」；不够时提示「回本境洞府「修炼→破境」后开放 化神云海」 |
| 3 | 出行列表锁定文案写明门槛 | 由「先在洞府破境」→「先在洞府破境至化神」 |

规则与数值未改，仍然**不允许只靠打首领跳过破境**。

## 五、给玩家的临时说法（未升级前）

> 婴灵古墟打完首领后如果化神云海还锁着，请先**回本境洞府 → 修炼 → 破境条件**，
> 完成「元婴问心」并突破到化神；若境界已经是化神，**退出重进一次**即可看到新地图。

## 七、同类风险自检（已顺带确认）

- `recalcUnlocked()` 用 `Math.max` 只增不减，不会把已开图收回
- `normalize` 载入时按同一规则重算，旧档不会因为本次改动丢进度
- 旧五图仍走 `recalcUnlocked` 的等价逻辑（i≤4 条件与原来一致）
