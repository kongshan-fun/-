# 青岚问道 V14.1 · 场景战斗规则

## V14.1 · 场景直接交互

- 每个地点固定 **6列×4行＝24个格位**，统一使用黑白文字矩形，资源显示字样、名称和当日剩余次数。
- 野外出现可直接点击的妖兽格，点击即进入真实回合战斗；胜利时同格变成「已清」，**次游戏日恢复**，撤离、失败不会算作胜利。地图移动的少量突发遭遇依然保留。
- 首领也以文字格出现。需要先完成本境封印，进入首领位置后点击「挑战」才开始斗法，重复挑战仍有每日限制。
- 旧前十个资源编号保持不变，新增节点11～24号独立记录采集次数；角色、地图位置和各档案彼此隔离，读取旧V14存档时自动补全怪物节点记录。
- 主屏不可整体滚动；所有成功、工具不足和怪物已清等反馈均为悬浮提示，不挤压资源和九宫格。
