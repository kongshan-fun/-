## 三、验收失败的两个夹具问题（下一步先修这两个）

1. **seed 档缺 `rebuilt:1`**
   `tools/mk_play_page.cjs` 生成的 seed JSON 不经过 `fresh()`，因此没有标记 → 会被误判成旧档。
   修法：在 mk_play_page 的 seed 对象里补 `"rebuilt":1`。

2. **验收脚本没有走完前沿页**
   游戏进入顺序是「种族页 → 档案页 → 档位」，`tests/v943_reset_flow.cjs` 直接点 `[data-a="slot"]` 点不到。
   修法（二选一）：
   - 在脚本里依次点 人族 → 第 1 档（拿到真实选择器后照抄）
   - 或直接生成一个"seed = 旧档"的试玩页，让页面自动进入该档（更稳，推荐）
