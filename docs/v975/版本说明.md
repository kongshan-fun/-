# V90.75 · 洞天十二阶

## 变更内容

### 唯一洞府
每一世经营一座洞府，不再到每个地图重复定居。洞府按钮可直接进入，离开后回原探索位置。洞府内保留营建、修炼、仓库、炼器、炼丹、功法和灵田。战斗与秘境中禁止进入，避免绕开战斗消耗或随身负重。

六类普通建筑均开放十二阶。对应关系为第N图、第N阶设施、第N阶装备配方；升级还需要相应境界和道材。地图解锁、角色境界仍是不同的进度，不把修为高等同于已打过首领。

材料容量是重量单位，装备另计件数；不是浏览器可用存储字节数。高阶仓房依然受浏览器实际配额制约，写入失败时游戏会提示导出，不能许诺所有600档都装满。

旧版各地洞府合并物资，设施按等效最高阶保留。旧四阶对应新九阶、旧五阶对应新十二阶，不要求已投入高阶资源的玩家重新从低阶养起。新角色则正常逐图成长。旧灵田到期产出及未满一轮时间保留；未建仓房时产出保留待领取。

### 赋灵修复
修复元婴以后读取停用道行池而始终提示修为不足的问题。统一读取并扣除当前修为xp，不降低已获境界；扣除后实时刷新圆满状态。失败预检不消耗随机数。锁定索引去重，禁止锁住全部槽位后无效消费。赋灵重抽计数按真实装备对象隔离，不因其他角色同名g1装备而串档。

### 主线与见闻
当前目标从真实境界、修为、地图仪式、首领和下一图门槛生成。旧故事移入可选见闻，不强制补做金丹雷考、元婴问心。已经做过的选择保留，未经历的故事不自动判完成。修复破境页使用不存在的s.stageIndex导致圆满判断错误的问题，同步图鉴与帮助。

### 分阶补给
十二张地图分别对应养元丹、聚灵丹、灵膳、灵饮，新增48个可炼制道具。回血/回灵按道具对应境界的基准属性恢复，低阶药不随角色最大气血无限增值。战内战外走同一补给效果定义，战内回血回灵占一回合；灵膳、灵饮仅限战外。

四格快捷补给分别为回血、回灵、食物、饮水。选择和库存按当前档位保存，支持关闭重开；耗尽明确提示，不自动使用别的珍贵丹药。仓库补齐行装也按当前四格配置提取。
