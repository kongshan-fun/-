# V90.77「灵息辟谷」功能与上线边界

基于本轮已有 V90.76 冻结文件（SHA256 68629D09E503A13DAC31C5C0E8CE27117ADF69344D5101A4855F48B0E99FF69D），不改地图、装备、建筑、敌人或广告奖励数值。

## 玩法
- 饱腹、饮水上限保持100。第1–4境普通消耗100%；5–6境75%；7–8境50%；9–10境30%；11–12境15%。
- 第七境可选开启灵息辟谷，默认关闭。沿用现有 energy/spirit 资源；高境人族显示真元，妖族显示妖元，不新增第三套资源。
- 每1点能量抵扣合计2点剩余普通食水消耗。先留出行动和环境能量；额外抵扣最多用掉高于40%最大能量的部分。
- 战斗、调息、休整和吐纳暂停额外抵扣；境界自然减耗依旧生效。环境额外饮水不减免。暂停不等于关闭，资源恢复后自动继续。
- 辟谷不补满食水，不直接治疗气血。食水匮乏仍影响休整恢复，不能靠“抵扣→回灵”制造零补给回血循环。
- 小数消耗使用千分点累计；能量预付余额也持久化，开关、刷新和存档往返不清零，不重复扣费。

## UI与存档
- 第5境为短提示；首次第7境领悟弹窗明确默认不勾选，可确认开启或暂不开启。
- 第9、11境为短提示，不打断为另一套强制任务。
- 高境旧档首次进入直接适配一次，不要求重新突破；寿尽救援优先，不与领悟弹窗重叠。
- 确认领悟直接回到修炼父页，与实际开关、自然减耗、暂停原因在同屏呈现。
- 选择、提示状态、消耗余量只保存在当前难度/种族/档位。写盘失败时回滚设置，不显示成功。
- 速通规则改变，本机榜使用V90.77独立key，旧榜原key保留不删除。平台官方榜未接入、未更换、未提交。

先导出旧版JSON；解压H5包并在固定来源中使用。新界面默认不消耗能量，需自行勾选。旧版本不识别辟谷存档字段；回滚请用升级前导出的原始JSON，而不是把新存档交给旧版反复覆盖。
