# 山野修仙记 V90.62 · P0 存档完整性修复与验收

基线：`release/v90.61` 提交 `b1957affac7b5ad30478cad73d60841be0ba9235`，保留原始 V90.61 发布文件。只在独立分支 `fix/v90.62-p0-save-ledger-integrity` 上修改。

## 处理内容

1. **修为持久化**：存档 normalize 不再把修为限制为当前段所需值 - 1；36级 XP 可以继续增加；读取时按后期圆满状态重建待破境标记。支持修为溢出并在保存、重开、破境后保留。
2. **旧存档重置**：删掉余额低于补偿额就补发的逻辑；建立 RaceSlots.resetRebuilt 安全替换流程。先检查旧记录和新记录，补偿金额和领取标记同一条账本 setItem 写入，再以单次 setItem 写入新主档，最后尽力清理备份。已存在的 -rebuild-compensated 标记仍被尊重。主档落盘失败时原始主档不删，重试不再重复发放；其他档位与两族隔离。
3. **适配范围**：旧版 version 1/2/5/7–14 不带 rebuilt 的合法旧档走阶梯补偿，较老单角色档只能进入人族；无效、异种族及损坏档禁止自动重置。
4. **未修改**：怪物与越级压制、前四次直接晋升＋后七次固定伤害渡劫、伤害表、轮回玉广告可重复领取规则、TapTap 适配层。
