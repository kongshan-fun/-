# V90.64｜三档难度、独立存档与分模式排行榜

> 版本状态：**功能候选，未合并主线，未上线 TapTap**。基线为 V90.62 主线提交 `7554d8c4a2db8c451d731a5d8f2b0fab4787bae5`。
> 与现有 V90.63 TapTap 平台/存档专项并行开发，此处使用 V90.64 编号避免覆盖原计划。

## 一、产品规则（2026-10-23 确定）

| 模式 | 现有数值系数 | 当前升级所需经验 | 怪物气血/攻击/防御 | 固定雷劫伤害 | 飞升排行榜 |
|---|---:|---:|---:|---:|---|
| 简单模式 easy | 0.50 | ×0.50 | ×0.50 | ×0.50 | 不计入 |
| 标准模式 standard | 0.80 | ×0.80 | ×0.80 | ×0.80 | 标准榜 |
| 挑战模式 challenge | 1.00 | ×1.00 | ×1.00 | ×1.00 | 挑战榜（沿用旧榜） |

数值采用 `Math.max(1,Math.round(...))` 处理经验和敌人气血/攻击；护甲允许向下取整至零；固定雷劫伤害按本次护劫丹减伤后乘难度系数。**不修改**玩家自身基础气血、攻击、寿元、物资、奖励掉率、地图解锁、怪物技能逻辑或战斗操作，以免在一轮内引入额外平衡变量。上述规则是“原版需求与敌人强度系数”，不是所有业务数据一律乘系数；原有 XP 获得值仍不变，因此简单/标准可更快成长。

入世第一屏为「选择修行难度」，需要明确点击一项后才可继续到选择种族；流程为 **难度 → 种族 → 100 档案 → 先天天赋 / 轮回玉确认 → 入世**。继续游戏时可先选任意模式浏览独立档，具体已有角色创建后难度不支持修改。档案和游戏设置可见所属模式。

## 二、存档兼容

- 每个难度都有人族 100 档 + 妖族 100 档，总计最多 600 个档位，各自独立主档、备份、死亡标记、轮回账本、旧档补偿与天赋广告抽取次数。
- 挑战模式继续使用 **原始 V90.62 存储键不变**：`qinglan-wendao-v14-human-slot-001`、`qinglan-wendao-v14-demon-slot-001`。
- 简单/标准分别使用 `qinglan-wendao-v14-easy-human-slot-001`、`qinglan-wendao-v14-standard-human-slot-001` 等单独前缀。
- 原存档未保存 `difficulty` 字段时只允许按 `challenge` 读取。旧存档不会被迁移至简单/标准，也不会被新模式覆盖。
- 新存档写入 `difficulty` 且重新读取时校验身份；导入其他难度的 JSON 和跨模式写入被拒绝，不因同一种族/档位号码相同就串存档。
- 原来判为“需旧档重构重置”的角色仍只会在挑战模式弹出；不额外为新难度制造重置或补偿。
- 从界面切换查看其他模式时，后台正在玩的角色自动保存依旧绑定自己的原难度，不会被当前浏览选项污染。

## 三、排行榜口径

- 简单模式不产生任何本机飞升排行记录，也不得向 TapTap 官方榜提交战力/飞升成绩。
- 标准模式本机榜使用独立键 `shanye-v907-local-ascension-board-v1-standard`。
- 挑战模式本机榜继续使用原键 `shanye-v907-local-ascension-board-v1`，以前保存的无难度标记成绩均判为挑战。既有数据不删除、不洗榜。
- 两套本机榜支持页面标签切换、按种族筛选、导出带难度标记 JSON。单榜只允许本难度记录。
- **TapTap 平台的独立榜单是额外发布门禁**：当前旧平台适配层只配置了挑战模式的战力榜和飞升速通榜 ID。新增 `platform/taptap-difficulty-ranks-v964.js`，控制 SDK 内部自动、主动上报及设置页排行榜，保证简单模式永不误报、标准榜无官方 ID 时拒绝投稿，不能伪装成挑战榜。
- 标准模式需要开发者后台提供两个**新建的、与挑战模式均不相同**的客户端榜单 ID，分别用环境变量 `TAPTAP_STANDARD_POWER_ID` 和 `TAPTAP_STANDARD_SPEEDRUN_ID` 配置。**此阶段尚未从真实 TapTap 后台取得，禁止声称标准在线排行榜已生效**。
- TapTap 构建器为 `tools/build_taptap_v964_from_v9064.py`，使用原平台适配层（外部 V907 源）+ GitHub 内难度路由守卫；实际适配层和平台 ID 仍需 V90.63 的来源锁定与真机测试。

## 四、自动化验证与现有约束

- `node tests/v964_difficulty_modes.cjs`：三种倍率、三族参数（实际为人妖两族）、战斗数值、保存加载、原挑战键兼容、600 个档位隔离、双榜隔离、简单拒绝排名。
- `node tests/v964_taptap_rank_guard.cjs`：在线榜同步保护模拟，模拟无角色/简单/标准已配置/未配置/错误复用挑战 ID。
- `python3 tests/v964_difficulty_browser.py`：实际 Chromium 320×568、360×640、390×844；选择/返回/排行切换/重新打开旧挑战档/差异隔离。
- `python3 tests/browser_responsive.py`：6 视口原游戏装备、档案、洞府响应式回归。
- `python3 tools/check_entry_consistency.py --rebuild`：从冻结 V90.62 精确重建 V90.64，入口与发布文件字节一致。
- `python3 tests/v964_taptap_package_smoke.py`：用仓库历史 V90.10 内嵌适配层作为 **MOCK 兼容性夹具**，验证静态注入、JS 编译和标准独立榜 ID 参数；**不能代替真正 V907 平台适配器及 TapTap 容器验收**。
