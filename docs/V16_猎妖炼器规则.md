# V16 前五境：猎妖炼器系统

## 核心规则

每张地图首先在野外挑战不同妖兽，获得**必定掉落**的猎妖素材，与采集材料共同炼制装备。打造本境任一战备法器、完成当境祭坛，即可进入首领挑战。胜利后解锁下一境。高阶炼器室的精工装备更强，但每张图也有一阶炉坊可打造的过渡猎妖装备，防止远征因生产设施过低而卡关。

## 掉落与仓储

- `ENEMIES.loot` 为**必得物品**，只在真实战斗胜利时结算；`bonusLoot` 才进行概率判定。额外稀有材料不会成为首次首领的唯一获取渠道。
- 遭遇胜利后物资受行囊负重限制，超重留在原地等待拾取；装备有独立器囊和待拾机制。
- 妖兽主动挑战格每游戏日一次。后七境继续原有修行机制。
- 24格中第11、17、23格供妖兽主动挑战；额外显示的采集格与原10格共享当日资源额度。旧版前10格及其读档计数保持可用。

## 操作建议

首张图优先采草木制作木剑和道袍，再挑战低危草木精怪与灵兔。攒齐兽材，在洞府一阶炼器室造“木灵猎剑”，完成山门后打噬灵妖魇。第二张图去花田和灵潭刷鳞、露，造碧鳞短枪后打青潭蛟影，之后依次升级火、阴、星系列。
