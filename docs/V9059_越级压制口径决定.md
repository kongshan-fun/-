# 越级压制口径：确认保留（产品决定）

日期：2026-10-22
适用版本：V90.51 起（含 V90.59）

## 一、现行口径

越级压制按「地图名义境序 = zone + 2」与玩家实际境序比较：

```
gap        = max(0, (zone+2) − 玩家境序)
敌伤加成   = 1 + 0.10 × gap
我方输出   = max(0.20, 1 − 0.08 × gap)
```

`zone 0..4`（青岚等前五张图）**同样参与计算**，不做豁免。

## 二、实测影响（合法存档状态）

| 场景 | gap | 敌伤 | 我方输出 |
|---|---|---|---|
| Lv1 凡人初期 在 zone0（青岚） | 1 | ×1.10 | ×0.92 |
| Lv1 在 zone1 | 2 | ×1.20 | ×0.84 |
| Lv1 在 zone4 | 5 | ×1.50 | ×0.60 |
| Lv19 元婴初期 在 zone5 | 0 | ×1.00 | ×1.00 |
| Lv33 渡劫初期 在 zone9 | 0 | ×1.00 | ×1.00 |

全量枚举：合法状态中 `gap > 0` 的组合共 **45 个**，全部集中在 `level 1..18 × zone 0..4`（即前五张图、未达境七之前）。

## 三、产品决定（2026-10-22）

**保留现状，不做 zone<5 豁免。**

理由（产品侧）：

- 前五张图虽然不设 `major` 门槛，但名义上对应「感气~金丹」区间；玩家以凡人初期硬闯，被压制是合理张力
- 压制只影响伤害与输出，**不影响能否进入地图**，不会卡住玩家
- 新手实际体感：Lv1 在青岚 gap=1（敌伤 +10%），尚在可接受范围；真正的强压制（gap≥3）只会出现在玩家主动连续越图上

## 四、代码位置（便于将来改口径）

| 位置 | 说明 |
|---|---|
| `get zoneGap()` | 计算 gap，当前无 zone 豁免 |
| `get enemyBoost() / get playerDampen()` | 由 gap 派生 |
| `startBattle()` | 开局按 boost/dampen 调整对手 atk 与 maxHp |
| `normalize()` | 读档时用 `n.zone`/`n.level` 复算同一口径（V90.59 修） |

如将来改为「zone<5 豁免」，需同步改三处（zoneGap、normalize 的 `_gap`、v951 验收脚本的「凡人打青岚」断言）。

## 五、相关验收

- `tests/v951_zone_gap.cjs`：断言含「凡人打青岚 gap=1」——**该断言即本决定的固化**
- `tests/v959_combat_save.cjs`：确认压制系数在 startBattle 与 normalize 两侧口径一致
