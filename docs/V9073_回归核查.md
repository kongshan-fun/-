## 三、过程中发现并修掉的「测试侧」问题（不是产品 bug）

1. **play 目录传参错误**：`run_full_regression.cjs` 的第 2 参数应为**裸目录名** `jindan-v973`；
   传 `play/jindan-v973` 会让内置 HTTP 服务拼成 `play/play/...` → 404 → 8 层 UI 集体失败。
   我一开始正是这样跑的，误判了一轮；修正后 UI 层立刻恢复。
2. **旧 UI 测试的「等待入世」条件失效**：`!document.querySelector('[data-a="view-slots"]')`
   在空白页/难度页也成立，V90.64 引入难度门后会抢跑。已把 6 个测试的等待条件改为
   「body 含气血 且 有 top-buttons」（**只改等待，不改任何断言**）。
3. **V90.64+ fixture 需要自动走完难度门**：新增 `make_play_fixture.cjs`，
   注入种子存档 + 同步连点「难度 → 种族 → 档案 → 001 档」，生成 `play/jindan-v973`。
4. **并发跑两套回归抢同一 CDP 端口 9880** → 互相干扰，已改为一律串行、跑前清 msedge。
