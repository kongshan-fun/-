# 界面层级重构原则与结论（V90.11 – V90.14）

> 本文记录 2026-10 这一轮界面重构的**判定原则**与**落地结构**，供后续改动对照。
> 原则由用户明确给出，早期我按「屏数」判定是错误的，已纠正。

## 一、判定原则

判断一个面板「该不该拆」的标准**不是屏数**，而是**内容是否同质**：

| 情形 | 处理 |
|---|---|
| 一页里是**同一类内容**（仓库物资、配方列表、图鉴条目、教程正文、见闻条目） | **滚动正常**，不要拆 |
| 一页里塞了**多个不同功能**，还要逐个点击折叠 | **禁止**，这是「下拉条」反模式 |
| 功能之间 | 用**页面跳转**：父页入口行 → 子页 → 「← 返回」 |

**已确认「不用拆」的页面**（早期误判为需拆）：

- 教程 3.11 屏 —— 一篇连续正文
- 见闻 2.40 屏 —— 同类文本条目
- 炼制·品阶配方 1.45 屏 —— 同类配方
- 仓库 / 背包 / 图鉴 —— 同类物品

## 二、已落地的结构

### 修炼（V90.11）
- 父页 1.00 屏：境界 · 战力 · 吐纳/试剑 + 三个入口行
- 子页：`cultivate-trial` 破境条件 / `cultivate-art` 境界法门 / `cultivate-rest` 休整
- 破境卡片改用 `progGuide('core')`，显式列出**三重雷劫行**（红 ✗ 0/3），
  修掉「雷劫未渡但『正式突破』按钮仍可点」的问题
- 入口标题境界无关：兜底用 `game.realmAt(s.zone-3)`，12 个境域全部验证
  （金丹/元婴/飞升保留专名，其余显示「突破 · 化神」等，低境界显示「晋升条件」）

### 炼制（V90.12）
- 8.48 屏 → 父页 1.00 屏：5 个品类入口，各带「可炼 N / 总数」
- 品类内配方 > 6 个时，先出**品阶段入口**（按 `r.tier`），再进配方列表
- 排序与「采集指路」原样保留

### 洞府（V90.12）
- **设施属于洞府本体，不做功能入口子页**（用户明确纠正过一次）
- 功能入口并成一行五格；建筑卡片 192 → 124px
- 删除与「修炼→休整」重复的休息结算条
- 1.59 → 1.06 屏

### 设置（V90.13）
- 六个不同类型分区 → 父页六入口 + 六子页（`set-save` / `set-life` / `set-char` /
  `set-visual` / `set-help` / `set-reset`）
- 2.00 → 1.00 屏，六子页均 1.00 屏

### 入口去重（V90.14）
- 顶栏移除「档案」（设置 → 角色与档案 已有同一功能）
- 背包外部入口 4 → 1：保留「本境仓库」，移除 行记 / 人物 / 前往炼制储物袋
- 人物页移除「前往炼制」
- 修正三处硬编码旧版本号与资质榜导出文件名

## 三、实现约定

- 子页即 `panel` 值：`cultivate-trial`、`craft-cat`、`craft-tier`、`set-save` …
- 判定函数：`isCultChild(p)`、`isSetChild(p)`
- 跳转动作：`cult-step`（修炼）、`panel-step`（炼制/设置，可带 `data-cat` / `data-tier`）
- 返回：`panel-back` 处理函数最前面按子页类型分流回父页
- 样式：列表入口行复用 `.cult-nav` / `.cult-nav-row`

## 四、构建链

每版从**冻结的上一版发布文件**构建，带三层断言：

1. 基线字节哈希校验
2. 每处替换的出现次数断言（防止锚点漂移/重复命中）
3. **动作集合不得减少**（`data-a` 集合比对）

| 版本 | 构建器 | 基线 |
|---|---|---|
| V90.11 | `tools/build_v911_from_main.py` | V90.10 |
| V90.12 | `tools/build_v912_from_main.py` | V90.11 |
| V90.13 | `tools/build_v913_from_main.py` | V90.12 |
| V90.14 | `tools/build_v914_from_main.py` | V90.13 |

## 五、内容一致性核查

- 教程正文 `D.HELP`：是否提到「档案/行记/储物袋/顶栏」→ **均 0 次**，无失效指引
- 引导步骤 `D.GUIDE`（11 步）：同上 → **均 0 次**，无失效指引
- 「行记」删掉背包入口后只剩 设置 → 帮助与记录 一条路（**可用，但更深**，未定是否挪到主线页）
