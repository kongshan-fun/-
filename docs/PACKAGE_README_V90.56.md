## 五、改代码的规矩（重要）

这是单文件项目，**改错一个字符就整页白屏**，所以纪律比常规项目更严：

1. **先跑语法检查**
   ```powershell
   node tests/syntax_check.cjs
   ```
   输出必须是「语法错误 0 个」+「自包含检查: 通过」。

2. **用构建脚本改，不要手改**
   ```powershell
   python tools/build_vNNN_from_main.py
   ```
   每个构建脚本都会：
   - 校验基线文件 SHA256（防止改错底本）
   - 逐条断言替换锚点命中次数（多一次少一次都报错）
   - 校验产物一致性（`index.html` == 发布文件）

3. **跑对应验收脚本**
   ```powershell
   node tests/v956_xxx.cjs
   ```

4. **跑全量回归**
   ```powershell
   node tests/run_full_regression.cjs <play页目录>
   ```
   当前应全绿（V90.55/V90.56 提交记录为 37/37）。

5. **小步提交**，出问题能 `git reset --hard` 退回。
