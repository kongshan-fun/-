# 青岚问道 V12 · 凡界飞升验收报告

## 功能变更

- **12张不同的8×8地图、768格**。原5张延续，新增7张：丹霞雷渊、婴灵古墟、化神云海、炼虚裂隙、合体仙城、大乘古道、渡劫天门。
- 增加9个凡界大境界（炼气、筑基、金丹、元婴、化神、炼虚、合体、大乘、渡劫），飞升为记录在角色存档里的终章，**仙界地图留待后续版本**。
- 新地图每张至少拥有2个专属采集资源、1个野生敌人、1个真实首领、1个祭坛与2套炼制装备。第六至十二境需回洞府消耗道行与专属材料破境。
- 渡劫天门最终飞升需要独立交互、最终特殊材料和道行；成功保存角色而非重开。
- 保留双角色独立存档、旧 V11存档升级、寿元/折寿永久轮回、黑白界面、左下九宫格和11步教程。

## 自动测试方法与限制

- 新增 `tests/v12_ascension.test.js` 按真实 `Game.act` 完成五境→后七境：采集实际节点，真实结算战斗、修坛、建洞府与炼制高阶武器，破境后解锁区域；未直接赋予等级/装备或将 `cleared` 标记置为 true。
- 这是**熟悉地图的自动规划器**，不等于纯新手盲玩测试，也不代表已经实现所有支线、境界每个子层和仙界内容。
- 用规划器自然获得的金丹、渡劫与飞升存档测试了真实浏览器界面。Playwright `page.set_content` + 测试替代 localStorage，不是 Android/iOS 真机持久保存认证。
- 尚未完成大型设备矩阵、不同路线数值分布、真实域名长期存储、人工无攻略五境至飞升耗时测试。
- GitHub 远端 CI 运行结论以实际 Actions 状态为准；在远端通过前不应合并 PR。
