# V90.78 迁移、回滚与发布边界

## 必须先备份
玩家先在旧版导出JSON，再在固定站点来源升级。新种植结构不可交给旧版覆盖保存。自动迁移不能替代异地备份。
首次保存V90.77或更旧的有效档位时，先保存 `-pre-garden-v978` 独立原档并读回校验。失败立即阻止覆盖；旧原档可从设置→存档与备份→导出种植升级前原档下载。
已存在的独立原档不被日常保存替换；损坏档和归属不符按原存档安全规则停止。普通自动备份与这份迁移归档相互独立。

## 自动灵田迁移
既有灵田等级保持，按等级分配空地块。迁移前已生成的最多3轮固定产物与旧pendingHarvest合并为待领，按仓库／背包可用空间领取，剩余保留。
原周期尚不足一轮时按剩余游戏时间生成一次结算凭据；这份凭据仅结算一次，不继续自动产矿。新种植与迁移补发不会重复累计。
迁移只在缺少garden字段时执行；重开、刷新、正常导入已升级档位不再次赠基础种子或旧收益。
旧V90.77寿尽待救援回执也能适配：保留原死亡快照，不把死亡回退到活着；成功续命才保存新结构并清除待决标记。

## 安全规则
种植写盘失败回滚本次内存变更，避免显示成功却吞种子。非法作物、越界地块、伪造时间和负数量拒绝载入，不静默截断。
满仓不丢失产物，部分收获记录remaining；成熟作物不能铲除，生长中清理须确认且不返种。
多标签同时写入、平台云端并发冲突仍沿用原项目约束，不能声称已由本轮解决。浏览器存储配额是现实限制；大归档失败时提示导出/清理而非默默删除。

## 发布状态
独立H5功能候选；没有部署到正式网址、合并main或上传TapTap审核。不含真实广告SDK、云端存档及官方排行榜的生产适配，尚需平台集成和真机验收。
源码堆叠关系：PR26→PR27→PR28→V90.78。本轮只更新独立开发分支。
旧全量测试保留。因工作台配方归属、种植字段和榜单规则改变，新增明确命名的适配回归文件，不能把不再有效的旧断言直接删掉后宣称通过。
