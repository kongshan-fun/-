# V90.78 验收口径

## 可重跑证据
- `stage12.json`：阶段一二自动工作台、配方归属、十二阶袋、赋灵门槛。
- `stage34.json`：阶段三四种植成长、升级、重复加载、满仓、seed掉落、600档隔离、迁移与配额故障。
- `acceptance.json`：当前精确index的26套回归，文件哈希绑定。本轮历史接口变更使用v978专用适配测试，历史脚本不覆盖。
- `browser/results.json`：默认HTTP来源、原生localStorage、真实Chromium点击、原始归档下载和六视口。
- `bigu-browser/results.json`及`rescue-browser/results.json`：原辟谷和寿尽保护的真实UI回归。
- `browser-render/`等：离线DOM模式（显式内存Storage）仅供容器内复核，不能代替上述原生测试。
- `player-natural-*.json`：真实行动策略，每次更改由游戏action执行，无XP/物品/属性/生命注入，无模拟广告。
- `regression/v975_100slots.cjs.log`：100档加速十二图里程碑，注入材料／修为／战斗属性以测试流程，不能冒充自然通关率。

## 测试范围与限制
截图使用隔离高境测试存档，不含玩家个人数据。默认自然策略只用人族与单个随机种子；成功与失败都写入报告，进程完成不意味着飞升成功。
本轮验证种植数值规则和资源守恒，不把默认成熟时间或概率宣称已经经过真实用户长期平衡验证。
最终打包只有在精准入口构建、引擎和原生浏览器检查完成后才允许CI生成。交付源码需独立解压重建，再核对index及发布HTML字节。
