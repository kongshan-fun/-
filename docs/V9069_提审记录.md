## 副作用说明（重要）

改成整数年后**并列会明显增多**：全服一局大约 20~40 年，
所以同分档位会扎堆。TapTap 榜按「先到先排」显示，并列时以提交时间先后为准。
如果想减少并列又保留可读性，可以后续改成「年 + 月」（如 35.4 → 354）——但那就又回到 ×10 的口径了，
按本次需求先以整数年上线。
