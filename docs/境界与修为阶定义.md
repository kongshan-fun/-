# 境界与修为阶定义（唯一依据）

> 本文件是所有境界、修为、属性、渡劫、地图强度、怪物与装备数值的**唯一依据**。
> 定稿：方案 B；数值部分标【草案】的需产品确认后转正。

## 零、内核声明

**这是一款生存经营游戏，修仙是题材与数值外壳。** 由此三条不可违反：

1. **一切关卡必须是"数值关卡"**：没有三重问答、没有剧情分支，只有"气血/攻击/护甲/丹药够不够"。
2. **成长必须来自养成**：突破、修炼、丹药、**做装备**、精炼。
3. **失败是损失，不是禁止**：打不过就重伤折寿，不清档、不锁内容。

## 一、三条定论

1. **12 境 × 每境三阶 = 36 段**，一图一境，每境分初期 / 中期 / 后期。
2. **「圆满」不是第四阶**，只是"后期修满、可以渡劫"的状态词。
3. **飞升不入阶、不入境**：第 12 图的终章事件，飞升后进入"凡界终章自由期"。

### 6. 重抽（刷新词条）

- 消耗 = 基础消耗 × `1.4^已重抽次数`（灵石与修为同乘），接受或放弃后计数重置。
- 连续 5 次不出玄纹以上 → 第 6 次**必出玄纹或仙纹**（保底，防手黑）。
- 可「锁定」已有好词条：锁定后重抽只刷未锁定槽，消耗 ×2。
- 界面显示：`当前赋灵 三级 凝纹 · 仙纹 7%` + 四档概率条 + 本次消耗 + 保底计数。

### 7. 与锻造的分工

| 系统 | 决定什么 | 熟练度来源 | 最高增益 |
|---|---|---|---|
| **锻造** | 基础属性 + 品质（决定槽数） | 锻造装备 | 品质期望 +29% |
| **赋灵** | 词条（穿透 / 百分比 / 吸血…） | 赋灵次数 | 词条强度 +43% |

两者各占装备强度的一半；都不跨档继承（存 `prof.forge` / `prof.spirit`，默认 0，旧档自动为 0，无需迁移）。

## 十一、存档迁移与旧档重置（version 15）

### 策略：迁移优先，重置兜底

| 旧档情况 | 处理 |
|---|---|
| v14（当前线上，V90.10 之后） | **自动迁移**（major / level / daoXp 换算，装备保留实例、按新表重算基础属性） |
| v1 / v2 / v5 / v7~v13 | 能换算就换算，换算不了的走重置 |
| 损坏 / 校验失败 | 走重置 |
| 检测到旧档但迁移失败 | 走重置 |

### 重置流程（只在"无法迁移"时触发）

1. 打开游戏检测到旧档 → 弹「系统重构说明」：
   > 为了整体游戏体验，我们对境界与修为体系做了一次重构，旧存档的结构已无法直接沿用。
   > 旧档不会被静默删除：可先「导出旧档 JSON」自行保存。
   > 确认后从零开始，并补偿 **500 轮回玉**（直接发到新档）。
2. 三个按钮：**导出旧档 JSON** / **从零开始（领补偿）** / **暂时不玩**（关掉，不做任何删除）
3. 确认清理：删主档 + 备份 + 陨落标记，写一次性标记 `qinglan-wendao-v15-reset-done`，只弹一次
4. 保留：本机飞升资质榜成绩不删（老玩家的脸面）
5. 补偿：新档开局 500 轮回玉

### 补偿阶梯（建议，比固定 500 更公平）

| 旧档进度 | 补偿 |
|---|---|
| 有飞升成绩（`ascended`） | **1,000 轮回玉** |
