## 修了什么（全部在测试侧）

### 1. 新增 fixture 生成器 `tools/make_play_fixture.cjs`

V90.64 起「入世第一步：选择修行难度」让旧 fixture 失效，因此统一生成：

- `<body>` 后注入 `<script id="seed-save">`（种子存档）+ `<script id="seed-import">`（写入 001 档，已存在不覆盖）
- `</body>` 前注入 `<script id="auto-entry">`：同一 tick 连点
  `难度(challenge) → 确认 → 种族(human) → 001 档`
- **自动入世放在 body 末尾**：像 v932 那种「剥掉种子块再跑」的测试会把 body 头部切片，
  放末尾才能在 noseed 页面里继续生效（这正是 v932、v938 之前失败的原因）

### 2. 六个 UI 测试的「等待入世」条件

旧写法 `!document.querySelector('[data-a="view-slots"]')` 在空白页/难度页也成立 → 抢跑。
改为 `document.body.innerText.includes('气血') && !!document.querySelector('.top-buttons button')`。

涉及：`v909_settings_browser`、`v914_ui_structure`、`v915_widths_matrix`、
`v917_book_hierarchy`、`v919_promo`、`v925_jade_repeat`。

### 3. `v925_jade_repeat` 的入世导航

旧路径「顶栏档案 → 列表」已被 V90.64 移除。改为：
`设置 → 角色与档案(set-char) → characters → 难度页 → 确认 → 种族 → 档位列表 → 002 档 → 命格确认`，
并兼容 `slot-open` 带/不带 `data-role` 两种写法。

**结果 25/25 PASS** —— 顺带证明「轮回玉广告奖励可重复领取」按设计正常工作
（连点 3 次 100/200/300、刷新后 400、换 003 档独立账本、001 档不受影响）。

### 4. `v951_zone_gap` 的两条源码断言

难度分级接入后公式多了 `*scale`：

```js
atk   = Math.max(1, Math.round(e.atk * (repeat?1.25:1) * this.enemyBoost * scale))
maxHp = Math.max(1, Math.round(e.hp * (repeat?1.25:1) / this.playerDampen * scale))
```

断言同步为 `… * this.enemyBoost * scale` / `… / this.playerDampen * scale`，
标签也改成「× 难度系数」，不再用旧形态匹配。**结果 12/12 PASS**。

### 5. `v910_file_launch_check` 的入口判定

`hasEntry` 原来只认 `choose-role` / `characters`，而 V90.64 首屏是难度页；
改为 `difficulty-choice` / `choose-role` / `characters` 三者之一。
`hasNav` 改为「顶栏按钮存在 或 洞府入口存在」。**结果 PASS**。
