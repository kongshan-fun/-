## 二、过程中发现并处理的两个问题

### 1. TapTap 版「斗法中能打开设置面板」（适配层相关）

- 普通版：`openPanel` 允许 help/settings/log/book，但 `render()` 在斗法中把 `panel` 置空 → 实际打不开。
- TapTap 版：适配层的面板观察器/注入会多触发一次渲染，导致面板留下来 → 违反文档「斗法中开面板都被拒」。
- 处理：构建期注入 P8，把 allowlist 改为硬拒绝。修后 v931 战斗界面 **25/25 PASS**。

### 2. `-backup` 逐字节比较过严（上游 V90.74+ 行为）

- 诊断：`s2` 3912 B / `-backup` 3913 B，键集合一致，只差 `atHome:true` 与 `atHome:false`。
- 原因：导入流程中先发生一次自动保存，备份捕获的是那一刻的档（身份字段、键集合都一样）。
- 处理：断言改为**语义等价**（键集合 + race/character/seed/level/zone 一致），保留原意且不再脆弱。修后 24/24 PASS。
