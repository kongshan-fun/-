## 功能
第八图「化神云海」原图内部坐标 (3,3)，玩家需元婴/化形及以上修为；此处不是炼虚（P5）地图，也不是破境必经。已有地图添加一个固定探查入口，不另起地图，不更改原 Boss、装备、飞升和既有技能公式。镜台初访→核验古阵印痕→核验残音→辨识三卷中唯一真迹；真迹位置与本档种子和种族有关，两个独立证据共同排除两份伪卷。两族对应原有技能体系，断碑早期抉择仅改变叙述，不操纵真卷。
观镜15分钟/灵力4/食水各1，两证各25分钟/灵力7/食水各1；选择35分钟/灵力10/食水各2。错误选择造成明确预告的实际扣血，原 collapse 折寿规则仍适用，次日恢复尝试资格。两证可以分次核验，退出没有额外成本，结果随种族/存档隔离。正确后只发一次既有「化神果×1＋上古残卷×1」，由原 loot() 处理负重与落地，不增加永久技能或额外战力。见闻册新增第六卷《云镜残书》，未抵达者无真相剧透。固定顶栏与五导航继续沿用原版层级。
在 `flags.mirrorTrial` 内保存 started、clues、rejected、complete、choice、lockedUntil；旧档没有字段则默认尚未进入，非法导入证据被规范化过滤；未更换原 save version/namespace。
