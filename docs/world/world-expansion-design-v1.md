# 《山野修仙记》十二境奇遇、天劫、越境秘境与仙人遗府 · 设计总纲 V1.0

> 决策日期：2026-10-17。设计基线：本地完整游戏 V79；首轮实施从 V79 增量开发。GitHub 主分支目前仍是早期 V9 工程，**本总纲不代表主分支已包含 V79 的功能**。
> 状态：总纲冻结（允许通过显式变更记录修订），游戏功能按独立轮次交付。不自动上线，不调整 Boss 或常规妖兽强度。

## 1. 项目目标与不变量

**目标**：每个境界不仅有更高数值，还要解锁新的修真经历：上古传承、渡劫、因果、异种敌人行为与可冒险的越境遗迹。玩家可提前发现高阶内容但不能绕过学习、战斗、装备和破境门槛。

**必须保留**：人／妖两族路线和各100独立存档；12张8×8主图；已有12处5×5秘境；洞府／仓库／装备／功法／血脉；九霄 Boss 技能；原有修为、道行、折寿和飞升规则；三主题、顶部状态与底部五项导航；本地图鉴与返回逻辑。全新事件**不得**直接造出跨境毕业装备、无限刷奖励、改动原有战力公式。

**风险边界**：有危险不等于不可预告的秒杀。高阶禁制用明示危险标记、探查提示与可撤离行为；误判可以重伤、战败、折寿，仍沿用现有失败结算。严重风险前显示当前危险与准备建议，不能偷扣生命。

## 3. 核心新增机制的约束

### 3.1 越境遗府（首轮落地）

筑基阶段先在**天阙遗境**发现“丹痕遗府·前庭”。只开启碑廊和外围阵纹调查；金丹核心传承延后开放。高阶门槛决定深处能否进入，而不是阻止提前发现。奖励以少量现有材料、情报与未来解锁线索为主，不得产出跨境成品法宝。可重复阅读线索，但一次性奖励/试炼严格防刷。

首阶段只添加一个确实可玩、可返回、可存档的外围调查点，不新增第13张大地图，也不改12处原秘境。

### 3.2 天劫差异化

- 金丹：凝丹雷劫，蓄灵／承雷／防守，不强制叠一个完整 Boss。
- 元婴：问心魔劫，通过真实选择和既有状态做出判断。
- 炼虚：裂隙风险、空间躲避及预测。
- 渡劫／飞升：九霄分阶段雷劫与终局叙事。

使用气血、灵力、护体技能、现有补给和寿元，不新增“雷抗评分”或长期堆叠百分比。

### 3.3 因果与寻仇

用少量离散**剧情状态**代替全局善恶、仇恨或 NPC 社交大数值。至少一条多境故事具有早期选择→后期回应→结局回收；后续事件根据实际所做选择互斥触发，避免重复领取与信息穿越。

### 3.4 高境界敌人

在已有“预告→防守／施法／攻击”回合系统上添加行为差异，优先设计封灵、假象、护阵、延迟招式与虚空错位，不全线增加攻击系数。单境一项新行为足够。

### 3.5 仙人遗府

渡劫前可选：遗仙问心→残缺仙禁→传承终试。作为非必通的高级挑战，不额外卡住原飞升主线，不宣称仙界大地图开放。不制作可反复刷新的真仙本体 Boss。容许失败和撤退，关键风险有明显警告。

## 4. 统一页面和存档约定

- 事件入口位于现有地图上；主页面依旧上留状态、下留五项导航，中间可完整覆盖。子页返回上级；地图展开收起要恢复前页。
- 一级地图格和图鉴仅展示简明状态；二级详情展示背景、前置、风险、选项、收益或线索，不在列表堆长文。
- 三主题语义色：危险浅红、传承淡紫、自然绿色、珍贵金色；极简黑白保持无彩色。
- 事件应能存读档、按种族＋档位隔离；同一项不可重复领取；低境旧档没有新字段时必须能以默认值恢复。
- 全部奖励走既有 loot/装备/功法接口；不给角色直接写战力；不改变 Boss 数值与 12 境数据。
