## 功能实现
1. 第六至十二图（内部索引 5—11）七种战斗异能：封灵、幻形、蓄势、错位、护阵、反制、雷云；分别应用在本境普通高阶妖兽和首领。所有异能都有战斗意图提示，护阵/蓄势可中途保存恢复。原每四回合首领绝技仍优先执行，没有整体提高敌人的基础 HP、攻击、护甲、战利品。
2. 三类高境异兆：逆行天象、失名遗响、护山残阵；每种族、每档位、每境单次，生成位置受角色当前随机种子决定且保存，不在祭坛、首领、界碑、已有剧情格触发。
3. 异兆可暂不参与、返回原格继续。绕行和深入有明确的时间/灵力/气血损耗与物品预览；成功、失败均会关闭本世该境奖励，防止刷取。没有新增广告货币、永久战力或者飞升强制门槛。
4. 旧 V14 存档缺失 `highEvents` 按空状态处理；输入字段会按合法区域、坐标、ID、状态做归一化；沿用原有角色、种族、档位和死亡规则。
5. 在现有手机界面增加探查按钮、异兆弹窗、风险文字和战斗意图预告。V89 P10 的可选九霄、直接飞升都保留。
