## 产生改动
1. 去掉原 character-v66 布局中顶部信息单独滚动和器囊独立滚动相互挤压的结构。新页面只有「随身器囊」一个滚动区；人物身份、战力、基础属性与双装备槽始终可见。
2. 把原来的大块战力明细改为紧凑人物首栏：种族、境界、寿元、战力；四项基础属性一行展示。不改变战力计算。
3. 武器、防具两个装备槽按双列独立显示，点击已装备槽可直接选中该装备；点击空槽筛选对应装备。当前筛选与槽位不匹配时，切换分类并定位实际装备。
4. 器囊从窄横向长条改为两列卡片网格，卡片保留品质、装备名、基础属性、当前穿戴或替换战力差值。顶部提供「全部 / 武器 / 防具」分段筛选与「品质 / 战力 / 精炼」循环排序，替换原来占空间的双下拉框。
5. 底部固定详情栏展示当前所选装备的附加词条与三个动作：穿戴、精炼、分解。每件卡片不再塞三枚按钮；分解增加确认/取消两步。
6. 所有 UI 数据依然从现有 `QGame`、`QCombatRating`、`D.RECIPES` 与存档状态实时计算；界面选择是临时状态，不写入游戏存档。其他面板仍沿用原有 `gearCard`。
7. 保留暖白松绿、黑白、流光三主题的原有主色与装备品阶色，不新增概念插画、渐变特效或游戏素材。针对窄屏和矮屏缩减非关键说明和内边距，保证器囊可操作。
