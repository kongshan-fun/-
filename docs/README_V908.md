# 山野修仙记 V90.8｜五阶洞府与高阶炼制 H5 对接包

## 当前状态
- 版本：V90.8 本地候选版
- 基线：V90.7 飞升结算与本机资质榜
- 形式：独立 H5 HTML，无需 APK，不新增网络请求或广告 SDK
- GitHub：尚未推送/合并；当前 GitHub `main` 仍是 V90.6
- 默认入口：`index.html`

## 快速试玩
1. 解压整个 ZIP。
2. 双击根目录 `index.html`，即可在桌面浏览器运行。
3. 如用于本地工程对接，优先比较 `index.html` 与 `releases/山野修仙记_V90.8_五阶洞府与高阶炼制版.html`，两者内容相同。

## 本次重点
- 洞府、仓房、炼器室、丹房、静室、灵田开放到五阶。
- 仓房容量升级为 80 / 180 / 360 / 650 / 1100。
- 四阶设施需洞府至少三阶；五阶设施需洞府至少四阶。
- 高阶道剑/法衣同步要求四阶或五阶炼器室。
- 装备精炼上限提升至 +5。
- 储物袋六至九阶要求四阶炼器室，十至十二阶要求五阶炼器室。
- 新增四阶回元丹、五阶道源丹，使用后分别恢复气血/灵力 120/60 与 220/130。
- 旧存档保留已有建筑、物资、进度；不会自动降级。

## 运行构建与测试
需要 Python 3 和 Node.js（建议 Node 22）。

在 ZIP 解压目录执行：
```bash
python tools/build_v908.py
node tests/run_v908_regression.cjs
```

构建脚本以 `releases/山野修仙记_V90.7_飞升结算与本机资质榜.html` 为固定基线，先校验 SHA-256，再生成 V90.8 的 `index.html` 和发布 HTML。

## 重要边界
- 本轮逻辑与自动化回归通过；没有在真实 Android/iOS 或 TapTap H5 容器内测试。
- 100 档主线测试为加速里程碑回归，不代表自然通关率。
- 本地资质榜和飞升结算保留 V90.7 行为；尚未接入云端排行榜。
- 游戏存档依赖浏览器来源的本地存储。更换域名、路径或容器前，请先导出旧存档。
