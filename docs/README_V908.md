## 功能核对

- 洞府、仓房、炼器室、丹房、静室、灵田均可到五阶；四阶设施需洞府≥3 阶，五阶设施需洞府≥4 阶。
- 仓房容量一至五阶：80 / 180 / 360 / 650 / 1100。
- 高阶道剑、法衣要求对应地图/境界及四或五阶炼器室；装备精炼上限 +5。
- 六至九阶储物袋需四阶炼器室；十至十二阶需五阶炼器室。
- 四阶回元丹恢复气血 120、灵力 60；五阶道源丹恢复气血 220、灵力 130（均不能超角色上限）。
- 保留十二阶储物袋、杀神/虚空储物袋、飞升、轮回、本机资质榜与旧档兼容规则。

## 正确的构建与测试命令

需要 Python 3 与 Node.js（建议 Node 22），在**仓库根目录**运行：

```bash
python3 tools/build_v908_from_main.py
python3 tools/extract_v908_tests.py
node tests/run_v908_regression.cjs
```

构建脚本首先校验 V90.6 冻结基线和 V90.7/V90.8 补丁输出的 SHA-256，然后对 **V90.8** 应用统一标题，生成 `index.html` 与 V90.8 发布文件；历史 V90.7 继续保留原名原内容。**旧说明中的 `tools/build_v908.py` 不存在，不能使用。**
