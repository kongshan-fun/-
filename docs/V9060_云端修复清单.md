## 问题 1：战斗中存档失败（最高优先级）

### 现象
战斗中每次自动保存都会弹：`存储未成功，先导出当前进度：Cannot read properties of undefined (reading 'enemyBoost')`。战斗外不报。

### 根因
`slots.save()` 内部会 `new Game(game.state())` 走 `normalize`。`normalize` 重建 combat 时用了 `this.enemyBoost`，而 `normalize` 是普通函数，**`this` 为 undefined** → 抛错 → `persist()` 捕获 → 弹提示。

该 bug 由 V90.51「越级压制」引入，同一段公式被复制到了 `startBattle()` 和 `normalize()` 两处。

### 修改位置
`index.html`，`function normalize(o) {...}` 内，`n.combat={...}` 的重建块。

### 原文（在 normalize 内，注意缩进是三空格）

```js
   const training=t==='dummy',repeat=!!o.combat.repeat,maxHp=Math.round(e.hp*(repeat?1.25:1));
   n.combat={type:t,hp:integer(o.combat.hp,1,maxHp),maxHp,atk:Math.round(e.atk*(repeat?1.25:1)*this.enemyBoost),armor:e.armor,
```

### 替换为

```js
   const training=t==='dummy',repeat=!!o.combat.repeat;
   /* 越级压制系数必须由 normalize 自己算：这里没有 this */
   const _self=Math.min(12,Math.ceil(Math.max(1,Math.min(36,Math.round(n.level)||1))/3));
   const _zr=Math.min(12,Math.max(1,Number(n.zone)+2));
   const _gap=Math.max(0,_zr-_self);
   const _boost=1+0.10*_gap,_damp=Math.max(0.20,1-0.08*_gap);
   const maxHp=Math.round(e.hp*(repeat?1.25:1)/_damp);
   n.combat={type:t,hp:integer(o.combat.hp,1,maxHp),maxHp,atk:Math.round(e.atk*(repeat?1.25:1)*_boost),armor:e.armor,
```

> 注意 `maxHp` 要 **÷ _damp**，与 `startBattle` 同口径；否则刷新页面后怪物血量会变。

### 自检
- 全文搜索 `this.enemyBoost`，只应剩 `startBattle()` 里的 1 处；normalize 段必须为 0。

## 问题 2：破境分流（金丹以下直接晋升）

### 需求
- 进入境序 **1→5**（凡人/感气/引气/炼气/筑基）的跨境：点「晋升」，**不掉气血、不耗护劫丹、无伤害页**
