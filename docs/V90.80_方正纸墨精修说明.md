## 本轮改动

## 交付与回滚

- `index.html` 为自包含 H5，可直接离线打开。
- 构建命令：`python tools/build_v980_from_v979.py`。
- 回归命令：`node tests/run_v980_acceptance.cjs`。
- 实机截图复现：`python tests/v980_visual.py --offline-dom`（本地 Chromium）或在可访问 localhost 的 CI 中执行 `python tests/v980_visual.py`（原生 HTTP/LocalStorage）。
- 此版为视觉精修，不主动替换生产，不改变存档兼容性。跨网址、浏览器及设备时先导出 JSON 存档。
