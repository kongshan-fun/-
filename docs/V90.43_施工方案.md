## 一、旧档处理（不迁移，一律重置 + 补偿）

| 项 | 规定 |
|---|---|
| 判定 | raw.version <= 14 即视为旧档 |

| 按钮 | 导出旧档 JSON / 从零开始（领补偿）/ 暂时不玩（不删） |
| 补偿 | 飞升档 1000 · 大境界≥6 或首领≥8 → 600 · 其余 300 |

**因为不做迁移，这一版不需要写 v14→v15 的字段换算**：normalize() 只需识别旧 version，交给重置流程。工作量比原方案小一半。

## 二、战力公式 v2（改为随境界放大，不做归一化）

### 产品结论

**战力就应该膨胀**：修仙到后期战力高本来就合理，数字越大越有推境界的动力；顺带把旧榜的高分自然挤下去（旧榜最高约 9,103，新体系金丹就已经 18,986）。

所以不压缩、不归一化，**保留原公式结构，只把境界系数从 `major` 换成 `境序`**：

```
raw    = 300 + maxHp×2 + maxSpirit×0.7 + attack×55 + 天赋加成
weapon = 武器实际值 × 55
armor  = 护甲实际值 × 75
affix  = Σ 词条值 × (会心/术威/吸血 8，其余 5)
境界系数 = 1 + (境序 - 1) × 0.12        ← 12 境上限 2.32（旧版 major 8 只有 1.96）
战力 = round( (raw + weapon + armor + affix) × 境界系数 )
```

### 规则

| 项 | 规定 |
|---|---|
| 触发条件 | 读取到旧档且 `normalize()` 迁移失败 |
| 弹窗次数 | 只弹一次，写 `qinglan-wendao-v15-reset-done` |
| 选「暂不玩」 | **不删除任何数据**，直接关闭 |

| 补偿 | 有飞升成绩 1000 / 大境界≥6 或首领≥8 → 600 / 其余 300 |

## 四、界面新增与改动（按既有规范）

| 界面 | 类型 | 规范要求 |
|---|---|---|
| 渡劫确认页 | 面板子页（`cultivate-trial` 内） | 一屏、三行数值、无选项、无背景色 |
| 锻造熟练度条 | 炼制页顶部嵌入 | 不新增页面，只加一行 |
| 赋灵界面 | 面板子页（`craft-spirit`） | 父子页跳转、三宽度验收 |
| 旧档重构弹窗 | 模态 | 复用现有 `modal` 结构，禁自定义背景色 |

**统一验收口径**（照 `docs/界面层级重构原则.md`）：
- 320×568 可滚但 ≤1.35 屏；≥360 必须 ≤1.02 屏
- 每次改完出**三宽度截图**（320/360/390）与前后对比
- `data-a` 动作集合只能增，不能删
- 全量回归 + 存档兼容测试必须全绿
