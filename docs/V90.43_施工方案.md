## 一、旧档 → 新档 迁移映射（version 14 → 15）

### 1. 境界映射（旧 major → 新境序）

| 旧状态 | 旧 major | 新境序 | 新境界 |
|---|---|---|---|
| level 1~9 | 0 | **4** | 炼气（新增的 1~3 境是新手内容，老档直接跳过） |
| level 10~18 | 1 | **5** | 筑基 |
| 破境 1 次 | 2 | **6** | 金丹 |
| 破境 2 次 | 3 | **7** | 元婴 |
| 破境 3 次 | 4 | **8** | 化神 |
| 破境 4 次 | 5 | **9** | 炼虚 |
| 破境 5 次 | 6 | **10** | 合体 |
| 破境 6 次 | 7 | **11** | 大乘 |
| 破境 7 次 | 8 | **12** | 渡劫 |
| 已飞升 | 9 | **12** | 渡劫（后期）＋ `ascended` 保留 |

> 为什么老档跳过 1~3 境：凡人/感气/引气是给新玩家铺的 3 段启蒙。老档已经在炼气以上，把它们降回"凡人"等于抹掉进度。

### 2. 阶与 level

```
阶 = 旧 level 1~9   → ceil(level / 3)        （1-3 初期 / 4-6 中期 / 7-9 后期）
阶 = 旧 level 10~18 → ceil((level-9) / 3)    （10-12 / 13-15 / 16-18）
阶 = 旧 major >= 2  → ceil(旧 daoXp / 旧 needDao × 3)，最小 1
新 level = (新境序 - 1) × 3 + 阶            （范围 1~36）
```

### 3. 修为进度（不让人白刷）

```
旧 major <= 1：新 xp = 旧 xp / 旧 required × 新该段需求
旧 major >= 2：新 xp = 旧 daoXp / 旧 needDao × 新该段需求
```

即"按百分比保留进度"，不会出现"修了 90% 忽然归零"。

### 4. 属性重算

| 项 | 处理 |
|---|---|
| 气血 / 灵力 / 攻击 | **按新表重算**（旧值不保留，因为新表是 70 倍量级） |
| 装备实例 | 保留 id / 品质 / 精炼 / 词条；**基础值按新表重算** |
| 词条 | 保留 id 与品阶（旧词条统一标为「凡纹」），数值按新表重算 |
| 洞府 / 背包 / 仓房 / 图鉴 / 旗标 / 秘境 / 支线 | **原样保留** |
| 寿元 | 保留绝对值（旧 60 年不会变 6 年） |
| 轮回玉 / 账本 / 飞升榜 | 原样保留 |

## 二、战力公式 v2（必须同步改）

### 现状（会被新数值撑爆）

```
raw    = 300 + maxHp×2 + maxSpirit×0.7 + attack×55 + 天赋加成
weapon = gearBonus(武器) × 55
armor  = gearBonus(护甲) × 75
affix  = Σ 词条值 × (会心/术威/吸血 8，其余 5)
realm  = 1 + major × 0.12
total  = (raw + weapon + armor + affix) × realm
```

问题：`maxHp × 2` 在渡劫境（28,500）就是 57,000，`attack × 55` 是 22,550 —— 战力会膨胀到 10 万级，且权重严重失衡（气血一项吃掉一半）。

### 新公式

```
基础分 = maxHp×0.35 + maxSpirit×0.25 + 攻击×8
装备分 = 武器实际值×8 + 护甲实际值×5
词条分 = 破甲×6 + 焰伤×6 + 护元×4 + 回灵×3
        + 会心×120 + 术威×120 + 吸血×80 + 回春×90
境界系数 = 1 + (境序 - 1) × 0.06
战力 = round( (基础分 + 装备分 + 词条分) × 境界系数 )
```

### 校验（两端与中点）

| 状态 | 计算 | 战力 |
|---|---|---|
| 凡人初期（裸装） | 180×0.35 + 90×0.25 + 6×8 = 63+22.5+48 | **≈ 134** |
| 金丹后期（基准装备） | +武器49×8 + 护甲34×5 | **≈ 1,400** |
| 渡劫后期（满打造） | 9,975 + 575 + 3,280 + 9,464 + 6,155 = 29,449 × 1.66 | **≈ 48,900** |

成长跨度 134 → 48,900（约 360 倍），量级控制在 5 位数字内，排行榜与卡片都不会溢出。

| 项 | 规定 |
|---|---|
| 触发条件 | 读取到旧档且 `normalize()` 迁移失败 |

| 选「暂不玩」 | **不删除任何数据**，直接关闭 |
| 选「导出」 | 走现有导出 JSON 流程，导出后仍可再选其他按钮 |
| 选「从零开始」 | 删主档 + 备份 + 陨落标记，开新档，发补偿 |
| 补偿 | 有飞升成绩 1000 / 大境界≥6 或首领≥8 → 600 / 其余 300 |
| 保留 | 本机飞升资质榜不删 |
