## 一、旧档 → 新档 迁移映射（version 14 → 15）

### 1. 境界映射（旧 major → 新境序）

| 旧状态 | 旧 major | 新境序 | 新境界 |
|---|---|---|---|
| level 1~9 | 0 | **4** | 炼气（新增的 1~3 境是新手内容，老档直接跳过） |
| level 10~18 | 1 | **5** | 筑基 |
| 破境 1 次 | 2 | **6** | 金丹 |
| 破境 2 次 | 3 | **7** | 元婴 |
| 破境 3 次 | 4 | **8** | 化神 |
| 破境 4 次 | 5 | **9** | 炼虚 |
| 破境 5 次 | 6 | **10** | 合体 |
| 破境 6 次 | 7 | **11** | 大乘 |
| 破境 7 次 | 8 | **12** | 渡劫 |
| 已飞升 | 9 | **12** | 渡劫（后期）＋ `ascended` 保留 |

> 为什么老档跳过 1~3 境：凡人/感气/引气是给新玩家铺的 3 段启蒙。老档已经在炼气以上，把它们降回"凡人"等于抹掉进度。

### 2. 阶与 level

```
阶 = 旧 level 1~9   → ceil(level / 3)        （1-3 初期 / 4-6 中期 / 7-9 后期）
阶 = 旧 level 10~18 → ceil((level-9) / 3)    （10-12 / 13-15 / 16-18）
阶 = 旧 major >= 2  → ceil(旧 daoXp / 旧 needDao × 3)，最小 1
新 level = (新境序 - 1) × 3 + 阶            （范围 1~36）
```

### 3. 修为进度（不让人白刷）

```
旧 major <= 1：新 xp = 旧 xp / 旧 required × 新该段需求
旧 major >= 2：新 xp = 旧 daoXp / 旧 needDao × 新该段需求
```

即"按百分比保留进度"，不会出现"修了 90% 忽然归零"。

### 4. 属性重算

| 项 | 处理 |
|---|---|
| 气血 / 灵力 / 攻击 | **按新表重算**（旧值不保留，因为新表是 70 倍量级） |
| 装备实例 | 保留 id / 品质 / 精炼 / 词条；**基础值按新表重算** |
| 词条 | 保留 id 与品阶（旧词条统一标为「凡纹」），数值按新表重算 |
| 洞府 / 背包 / 仓房 / 图鉴 / 旗标 / 秘境 / 支线 | **原样保留** |
| 寿元 | 保留绝对值（旧 60 年不会变 6 年） |
| 轮回玉 / 账本 / 飞升榜 | 原样保留 |

### 5. 迁移验收

- 用 `tests/v937_save_preserved.cjs` 模板改造：旧档 57 个字段逐字段对比
- 另加 3 个真实档样例（前期/中期/飞升）跑"迁移前后关键指标表"（境界、阶、气血、攻击、洞府等级、背包件数）

## 二、战力公式 v2（改为随境界放大，不做归一化）

### 产品结论

**战力就应该膨胀**：修仙到后期战力高本来就合理，数字越大越有推境界的动力；顺带把旧榜的高分自然挤下去（旧榜最高约 9,103，新体系金丹就已经 18,986）。

所以不压缩、不归一化，**保留原公式结构，只把境界系数从 `major` 换成 `境序`**：

```
raw    = 300 + maxHp×2 + maxSpirit×0.7 + attack×55 + 天赋加成
weapon = 武器实际值 × 55
armor  = 护甲实际值 × 75
affix  = Σ 词条值 × (会心/术威/吸血 8，其余 5)
境界系数 = 1 + (境序 - 1) × 0.12        ← 12 境上限 2.32（旧版 major 8 只有 1.96）
战力 = round( (raw + weapon + armor + affix) × 境界系数 )
```

### 规则

| 项 | 规定 |
|---|---|
| 触发条件 | 读取到旧档且 `normalize()` 迁移失败 |
| 弹窗次数 | 只弹一次，写 `qinglan-wendao-v15-reset-done` |
| 选「暂不玩」 | **不删除任何数据**，直接关闭 |
| 选「导出」 | 走现有导出 JSON 流程，导出后仍可再选其他按钮 |
| 选「从零开始」 | 删主档 + 备份 + 陨落标记，开新档，发补偿 |
| 补偿 | 有飞升成绩 1000 / 大境界≥6 或首领≥8 → 600 / 其余 300 |
| 保留 | 本机飞升资质榜不删 |

- 320×568 可滚但 ≤1.35 屏；≥360 必须 ≤1.02 屏

- `data-a` 动作集合只能增，不能删
- 全量回归 + 存档兼容测试必须全绿
